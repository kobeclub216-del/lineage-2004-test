| 項目 | 狀態 |
| --- | --- |
| D173 人物施法動畫 | 已發射的光箭遇到移動等動作中斷時繼續飛行，角色停止移動後不再跳回上一段施法動作 |
| D174 裝備與能力值 | 待有可確認版本的裝備資料，至少需初始裝備、裝備位置與限制、能力值加成及對應圖示。現版道具欄的藥水、天幣與快捷格繼續使用原本資料 |

## Windows 本批驗收

1. 從 `Magic-Test.html` 的村莊入口進入，將已學的光箭拖到快捷格，按對應 F 鍵後點哥布林。驗證 MP 7 → 4 → 1，第三次顯示魔力不足。
2. 打開背包或魔法視窗後按 Esc。開始選取光箭目標時，第一次 Esc 先取消選取，第二次關閉視窗。
3. 第一發光箭飛出去後點空地走一小段再停下。確認人物不會跳回施法動作，光箭仍會飛到目標。
