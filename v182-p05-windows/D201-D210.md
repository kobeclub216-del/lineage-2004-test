# D201～D210

- D201～D203：從潘朵拉買入匕首、皮夾克。售價 8、22 天幣出自[巴哈姆特舊《天堂》攻略百科](https://wiki2.gamer.com.tw/wiki.php?n=1512%3A%E6%BD%98%E6%9C%B5%E6%8B%89)。該表未標版本，作為舊版參考價，1.82 原價待確認。精靈匕首留在獨立測試模式。
- D204～D206：1.82 的能力值與職業限制待可信版本資料。購買沿用既有角色存檔，裝卸沿用 D200。
- D207～D208：沿用既有商店、背包與狀態窗尺寸。裝備圖示缺少可核對的對應，背包顯示名稱。
- D209：目前場景及素材清單以既有村莊、商店和哥布林為主，未找到可直接接入的新內容及完整資料。
- D210：交易回歸涵蓋扣款與入袋同時保存、裝備與存檔相容性、餘額與容量限制，以及寫入失敗。
