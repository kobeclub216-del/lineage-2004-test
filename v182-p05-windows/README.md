# 天堂 1.82 開發整合階段 D171

本目錄延續使用者已測試的 D170 Windows 程式，不取代首頁、選角、創角或既有版本目錄。

## 執行

下載本目錄全部檔案，解壓後開啟 `Start.html`；也可使用任意靜態 HTTP 伺服器。
**不能只下載 Start.html**，它需要同層 `assets/`。

- `Start.html`：既有村莊、商店與哥布林測試，不需另加查詢參數。
- `Gereng.html`：既有吉倫學習場景，沿用正式角色欄位。
- `Gereng-Test.html`：獨立學習測試存檔，不覆寫正常角色欄位。
- `Light-Bolt.html`：既有木人光箭預覽。

首頁、創角與選角仍有 D170 原本的外部參考圖片／動畫依賴；不宣稱完整離線可用。
遊戲畫面沿用 4:3，沒有新增圖框、替代美術或遊戲機制。

## 本階段修改

- 將 D170 的 61 個原有內嵌圖像／字型資產拆成檔案，保留原始位元組，並拆開六段程式以便維護與測試。
- 村莊哥布林經驗接回既有升級流程；保留超額經驗及等級上限，經驗條使用目前等級需求。
- 光箭發射後繼續飛行及結算，移動、轉向與 Esc 不再刪除已發射的光箭；發射前仍可取消。
- 光箭保存發射方向、目標座標、場景、角色欄位及遭遇識別，抵達時只結算一次，不能誤傷新遭遇。
- 商店買賣與吉倫學習共用原子存檔：成功寫入後才更新角色，寫入失敗不扣款、不變更道具。
- 交易拒絕不合法數量、超出安全整數的堆疊／金額及損壞數值。
- 木人套用既有可見像素命中容錯與遮擋檢查，與 NPC／怪物一致。
- 八方向轉向支援遠距座標；視窗失焦或失去指標擷取時清理按鍵／手勢。
- 修正舊 D86 測試頁的無限大圖層腳點，以及渲染器的預設人物深度。

## 驗證與待辦

在儲存庫根目錄執行 `npm test`，無需安裝第三方依賴。
GitHub Actions 在開發分支推送後執行測試，通過後產生 `lineage-182-windows-dev` 下載包。
自動測試涵蓋八方向、碰撞邊、改道、戰鬥一次結算、經驗成長、買賣存檔失敗、素材完整性及全部 28 組人物動畫配置。

本次執行環境 Chromium 因 `socket() failed: Operation not permitted` 無法啟動。
Node 測試、圖檔解碼及資料驗證**不等同 Windows 真實瀏覽器或 iPhone 實測**。

待辦：Windows 全流程視覺回歸、角色／視窗精細對位、歷史數值核對、吉倫與商店場景連接、完整怪物生命週期、更多魔法。
GitHub Pages 正式頁不隨本分支自動更新，本次不更動 main 或正式部署設定。
