D170 光箭測試

同一個瀏覽器內，兩個入口共用獨立測試存檔。首次進入提供未學光箭的 Lv.4 法師、100 天幣和 7 MP。

  1. 到吉倫之家學習光箭。開始遊戲後選「光箭測試法師」並進入遊戲。點吉倫，再點「學習光箭（100 天幣）」。確認顯示「已學會光箭」。再學一次應顯示已學會。
  2. 使用瀏覽器上一頁回到這裡，再到村莊對哥布林施放光箭。選同一角色，進入遊戲後點「魔法」→「光箭」→哥布林。站定再施放，確認 MP 減 3，光箭飛抵後哥布林才掉血。

每次施法後等動畫結束。若哥布林先倒下，可回角色選單後重新進入村莊再驗證。MP 少於 3 時應顯示「魔力不足」。

建議以本機 HTTP 開啟，兩個入口須使用相同的網址主機和連接埠。可在此資料夾開啟 PowerShell，執行 py -m http.server 8000 --bind 127.0.0.1，再前往 本機測試頁。
