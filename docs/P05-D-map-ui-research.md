- 遊戲入口：`v182-p05-test/index.html`，單一 HTML + Canvas。

- 地形類型：grass、dirt、water、bridge、tree、rock。
- 現有地圖為程式繪製的測試場景，不可誤稱為原版天堂 1.82 地圖。
- 人物顯示、地圖點擊座標、尋路與碰撞依賴現有 `screen` / `unproject` 與地形資料。
- P05-B4 為使用者已確認正常的基準：角色建立、選角、進入遊戲、人物動畫、撿取、戰鬥、背包與存檔均須保護。
- 撿取動作維持正常站立，不可恢復壓縮人物圖片的假動畫。

## 已查證的年代資料
1. 2004-07-27 的《Lineage: Heaven and Earth》發表報導明確提及介面改版，包括法術延遲計時、頭頂 HP/MP 顯示、文字巨集與聊天文字顏色選項。來源：https://worthplaying.com/article/2004/7/27/news/18284-ncsoft-launches-lineage-heaven-and-earth/
2. 2003 年的實際遊戲截圖收藏，可作為地圖視角與 UI 版面歷史比對，但不得直接視為 1.82 精確畫面。來源：https://hibiki.org/lineage/ss/index.html
3. 玩家回顧文章有 2004 年前後介面截圖，作為待交叉驗證的輔助資料。來源：https://forum.gamer.com.tw/Co.php?bsn=00842&sn=5815474

## 版本界線與資料政策
- 本專案以使用者指定的 1.82 版為主要還原目標；使用 2004 年原始資料做歷史查證。
- **不使用 2026 天堂經典版資料**作為缺漏補值或驗證依據。
- 私服頁面或後期地圖合集僅可提供查找線索，不能直接視為原始版本的可靠證據。
- 原版圖片、介面、地圖若未確認授權，不直接複製到公開 GitHub 專案；不能自行亂畫冒充原版。

## P05-D 後續實作順序（每步獨立測試）
1. 對照 2003–2004 實際截圖，整理介面區塊：聊天、HP/MP、快捷列、選單、人物與地圖的相對位置。
2. 查找可合法使用的地形圖塊與其尺寸、遮擋層、物件層；在確認前維持現有測試地圖。
3. 將地圖繪製與地圖碰撞資料分離；保留 40×40 地圖、座標轉換與尋路規則，不改既有角色 Sprite。
4. 先在開發分支進行單一小範圍視覺替換，確認人物不消失、點擊位置不偏移、可正常尋路、敵人與掉落正常。
5. 任何修改都先通過 JavaScript 語法檢查，測試通過後才部署 main。
