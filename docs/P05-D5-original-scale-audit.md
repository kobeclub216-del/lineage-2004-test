# P05-D5｜天堂 1.82 原版比例與素材還原驗證基準（開發分支）

狀態：**待實證量測，不得宣稱 1:1 還原完成**。適用範圍：2004 年 7 月的《天堂》1.82 原版；排除 2026《天堂經典版》數值及後期介面作為原版證據。

## 已有歷史依據

- 舊天堂畫面回顧，含 2004 前後介面截圖，但個別圖片版本仍需逐張鑑別：https://forum.gamer.com.tw/Co.php?bsn=00842&sn=5815474

- 舊天堂地圖檔案是多圖層 S32，現有 Canvas 菱形與幾何樹木不等於原版地圖：https://github.com/tony1223/L1MapViewer

## 當前程式數值（只是原型，不是 1.82 歷史數據）
- Canvas：800×600（4:3，視窗比例已確認，遊戲 UI 佈局仍待比對）
- 地圖格距：TW=56、TH=28（未驗證）
- 角色繪圖高度：drawHeight=58、anchorY=49（未驗證）
- 地圖：40×40 自製菱形圖塊，樹木、岩石、水、橋與怪物是 Canvas 幾何繪製（**未還原**）
- 角色：第三方 classanim 參考來源，方向與影格需逐類逐方向驗證；素材年代及授權未確認

## 量測程序（未完成前禁止隨意猜測數字）
1. 取得**能確定為 2004 年 1.82**的原始 4:3 截圖或同年代原始客戶端畫面，保留出處與日期。
2. 在截圖標記：可遊玩地圖區域邊界、底部 UI 高度、人物站立腳點、同一平面的相鄰地圖格距、人物像素高度、建築／樹木／怪物大小。
3. 至少以兩個場景、兩個不同角色方向比對；每項記錄「原圖像素、參考來源、測量誤差、信心水準」。
4. 用相同 800×600 畫布重現；角色腳點必須與地面接觸，物件遮擋按原版圖層順序，不可單純整張畫面縮放。
5. 使用原始地圖素材或經核准的相應資產；素材缺少時標註缺失，不得自行畫圖冒充原版。
6. 核對滑鼠點地面移動、八方向走路與攻擊、拾取、角色建立與快捷欄，並以實際瀏覽器截圖回歸測試。
